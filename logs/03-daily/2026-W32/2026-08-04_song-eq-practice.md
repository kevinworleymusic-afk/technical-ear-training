## Objective

Begin transferring the EQ-identification cues established with pink noise to music by using one selected reference song.

## Planned Procedure

1. Acquire one of the selected reference songs and record the exact song, artist, and version used.
2. Set a fixed, comfortable monitoring level.
3. Complete a short pink-noise EQ warmup using familiar settings.
4. Use the song for comparable EQ-identification practice, beginning at an audible boost and reducing it only when performance is stable.
5. Reset the trial counter whenever the frequency set, gain, number of boosts, or stimulus changes.
6. Record the frequency range, gain, Q, number of simultaneous boosts, trial count, accuracy, audible cues, and any differences between pink-noise and music listening.
