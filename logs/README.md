# Session Logs

Save completed practice records here using:

`YYYY-MM-DD_exercise-name.md`

Examples:

- `2026-07-26_frequency-band-identification.md`
- `2026-08-02_automotive-listening-walkthrough.md`

Logs should preserve incorrect answers as well as correct ones. The goal is to demonstrate repeatable improvement, honest confidence tracking, and the connection between critical listening and engineering verification.
