Use this template to plan ear-training instruction one week at a time. When planning beyond one week, begin with the [Monthly Critical-Listening Lesson Calendar](../01-monthly/MONTHLY_LESSON_CALENDAR.md), then refine the current week here. It treats the week like a teacher's lesson plan while preserving day-to-day adjustment based on evidence.

The listener chooses broad categories. The detailed session plan is then generated from the current [progress dashboard](../../PROGRESS.md), [chapter curriculum](../../chapters/), [daily warmup progression](../03-daily/DAILY_WARMUP_PROGRESSION.md), and prior session logs.

This calendar stores the broad categories and purpose for each named day. A day may be marked **Rest / Recovery** instead of assigning practice. Before each active practice day, generate the exact 12-, 13-, or 14-minute warmup timetable and objective-limited focused development block in that day's linked session log.

## Daily Generation Rule

For each planned day:

1. Read the broad warmup and development categories from this weekly plan.
2. Check the latest completed session and cumulative progress.
3. Populate the warmup with the appropriate software, source, task type, settings, cue, and exact time allocation.
4. Populate the development block with an objective, controlled variables, staged implementation, advancement decision, evidence requirement, and stopping rule.
5. Preserve the weekly category unless the evidence, fatigue, hearing condition, or software access makes an adjustment appropriate.
6. Record any adjustment and its reason in the dated session log and weekly review.

Populate the Monday-through-Sunday grid before the week begins. Keep technical settings in the session log so the calendar remains readable and the daily implementation can adapt to new evidence.
