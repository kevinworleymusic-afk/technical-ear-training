# Focused Development Block

Use this template after the timed daily warmup. The listener supplies a **selected focus**, and the block is then completed with a specific implementation plan using the current chapter evidence and progress dashboard.

Unlike the warmup, this block has **no preset duration**. It continues until the planned learning objective or stopping rule is reached. Trial count and elapsed time are recorded as outcomes rather than quotas.

## Stop Conditions

End the block when any one of the following applies:

- The stated learning objective or advancement criterion has been reached.
- Enough comparable evidence has been collected to make the next decision.
- Accuracy, confidence, or cue recognition has clearly stabilized for the session.
- Listening fatigue, discomfort, declining attention, or repeated careless responding makes further trials unreliable.
- A persistent software or setup problem prevents valid listening work.
- Continued attempts are no longer producing useful information.

A weak result is not a reason to force additional trials. Record it honestly and define the next exposure or easier comparison.

## Documentation Rules

- Matching, memorized identification, rapid identification, and exploratory listening remain separately labeled.
- Do not convert exploratory exposure into a mastery score.
- Change one meaningful variable at a time when evaluating progress.
- Do not pool results from materially different sources, settings, or task types.
- Record software/setup interruptions, but exclude them from listening-practice time and valid trials.
- Update the cumulative progress dashboard only when the setup and result are sufficiently defined and comparable.
