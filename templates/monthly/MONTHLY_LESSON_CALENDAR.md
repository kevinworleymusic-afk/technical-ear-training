## Calendar Key

- **Warmup:** List one or two broad categories.
- **Development:** List one broad category.
- **Practice:** Normal 12-, 13-, or 14-minute warmup followed by the objective-limited development block.
- **Diagnostic:** Use the exact 30- or 45-minute full diagnostic instead of an ordinary full practice session.
- **Recovery:** No formal listening practice, or only low-demand reference listening.
- **Log:** Add the dated session-log link when the detailed daily plan is generated.

## Monthly Instructional Sequence

| Week | Broad development emphasis | Warmup maintenance | Planned evidence or decision |
|---:|---|---|---|
| 1 | Establish or refresh baseline |  |  |

| 3 | Stabilize performance |  |  |
| 4 | Increase one meaningful difficulty variable |  |  |
| 5 | Test transfer or delayed retention |  |  |
| 6, if present | Review, diagnostic, and next-month planning |  |  |

The sequence is a planning guide, not a requirement to advance every week. Keep or simplify the current condition when the evidence does not yet justify progression.

## Population Workflow

1. Choose the month's broad development emphasis and maintenance categories.
2. Enter all dates in the Monday-through-Sunday grid.
3. Mark unavailable and recovery days first.
4. Assign broad warmup and development categories to active days.
5. Place 30- or 45-minute diagnostics where they can provide useful evidence without crowding normal development.
6. At the start of each week, refine the calendar entries in the weekly lesson plan.
7. Before each session, generate the detailed warmup timetable and development block in a dated session log.
8. Adjust future calendar entries when completed evidence supports a change, and briefly record why.
