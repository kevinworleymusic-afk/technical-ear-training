# Training Software Downloads

The standalone applications and supporting files used for this technical ear-training program are stored externally because individual software packages are approximately 1 GB and are not appropriate for normal Git repository storage.

## Download Folder

**[Open the Technical Ear Training software folder in Google Drive](https://drive.google.com/drive/folders/1WIuYLmHHPDWz2LhAHkrbhHOtvptYrD3T)**

## Repository Relationship

This GitHub repository documents:

- What each application trains
- How each exercise is performed
- Training results and progress
- Listening observations
- Connections between audible cues and engineering measurements

The Google Drive folder provides the large standalone software files used to complete those exercises.

## Access Note

The Drive folder must be shared as **Anyone with the link — Viewer** for portfolio visitors to access it. Availability of individual applications may also depend on operating-system compatibility and their original licensing terms.
